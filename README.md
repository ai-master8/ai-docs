# 🗂️ TagTree

**TagTree** — однофайловое веб-приложение для заметок с иерархией по тэгам. Иерархия задаётся не папками, а комбинациями тэгов: заметка с тэгами `работа, проект` появляется сразу в ветках `работа → проект` и `проект → работа`.

**Открыть приложение:** [ai-master8.github.io/ai-docs](https://ai-master8.github.io/ai-docs/)

Всё приложение — один самодостаточный файл [`tag-tree.html`](tag-tree.html): без сборки, зависимостей, CDN и внешних ресурсов.

## Возможности

- **Дерево по тэгам** — все перестановки тэгов (до 5 на заметку), счётчики уникальных заметок, перетаскивание заметок в папки.
- **Рейтинг 1–5** — звёзды в редакторе, на карточках и в просмотре заметки. Оценку можно поставить кликом, клавишами `1–5` на карточке в фокусе или через контекстное меню; повторный выбор сбрасывает её.
- **Полный просмотр** — клик по карточке открывает заметку целиком справа; заголовок, тэги, рейтинг, даты, Markdown и обратные ссылки.
- **Внутренние ссылки** — `[[Заголовок]]` в тексте превращается в ссылку на заметку; в просмотре показываются все заметки, которые ссылаются на текущую.
- **Редактор в правой панели** — не модальное окно: дерево и список остаются на месте. Есть индикатор «● не сохранено» и подтверждение при уходе с несохранёнными правками.
- **Markdown-редактор** — режимы «Редактор / Разделить / Предпросмотр», тулбар, поиск и замена, оглавление, счётчик слов.
- **Поиск** — по словам, тэгам, заголовку, датам, оценке, закреплению, задачам (`task:open`/`task:done`) и связям (`links:orphan`/`links:in`/`links:out`); область «Везде / В папке», подсветка совпадений, сниппет превью вокруг найденного, путь заметки в результатах, сортировка по релевантности, фасеты с быстрыми фильтрами по оценке, сохранённые представления (запрос + сортировка + область).
- **Быстрый переход** — `Ctrl+K`: папки, тэги, заметки, сохранённые фильтры и команды в одном списке с нечётким поиском.
- **Управление тэгами** — переименование, слияние, цвет, удаление, поиск похожих имён.
- **Надёжность** — корзина (20 заметок), версионные снимки (5), история заметки (20 версий), многоуровневая отмена (до 20 действий) и повтор, автосохранение черновика редактора и предупреждение о второй вкладке.
- **Экспорт/импорт** — JSON, Markdown, TXT, печать/PDF. Есть автосохранение в привязанный локальный файл.
- **Темы и мобильная вёрстка** — светлая/тёмная тема, адаптив под телефоны и планшеты.
- **Локальное хранение** — IndexedDB для заметок и localStorage для настроек, без сервера.

## Быстрый старт

### Онлайн

Откройте [ai-master8.github.io/ai-docs](https://ai-master8.github.io/ai-docs/) — приложение сразу готово к работе.

### Локально

1. Скачайте [`tag-tree.html`](tag-tree.html).
2. Откройте файл двойным кликом или через локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000/tag-tree.html
```

> При открытии через `file://` в Chromium хранилище привязано к **папке** с файлом, а не к самому файлу. Перенос HTML в другую папку или смена профиля браузера означает «нет данных». Для переноса между машинами используйте экспорт JSON или привязанный файл.

## Хранение данных

| Что | Где |
|---|---|
| Заметки и таблица тэгов | IndexedDB, ключ `noteTreeData_v1` |
| Резервная копия, снимки, корзина | IndexedDB |
| Тема, сортировка, свёрнутые папки, последнее место | localStorage |
| Привязанный файл | IndexedDB + File System Access API |

Если IndexedDB недоступна, приложение переходит на localStorage; если недоступно всё — данные живут только в памяти, но остаются экспорт и файловое сохранение.

## Поиск

Поле поиска слева. Под ним переключатель области: **«Везде»** — искать по всему архиву, **«В папке»** — только в текущей ветке (в корне недоступен). Кнопка **✕** очищает запрос, `Esc` делает то же с клавиатуры, `/` фокусирует поле.

| Запрос | Значение |
|---|---|
| `#работа` | обязательный тэг |
| `#"работа с пробелом"` | тэг с пробелами |
| `-работа`, `!работа` | исключить тэг |
| `title:слово` | подстрока в заголовке |
| `rating:4`, `rating:>=4`, `rating:<3` | оценка (операторы `= >= <= > <`, `0`/`none` — без оценки) |
| `pinned:true` / `pinned:false` | только закреплённые / только обычные |
| `since:2025-01-01` / `until:2025-12-31` | диапазон по дате обновления |
| остальной текст | подстрока в заголовке, тексте или тэгах (логика «И») |

В результатах виден путь заметки (`a / b` или «Без тэга») и кнопка **«в дереве»** — она очищает поиск, раскрывает нужную ветку и переходит в неё.

В фасетах над тэгами есть быстрые чипы оценки: **★ 3+**, **★ 4+**, **★ 5**, **Без оценки**. Сохранённое представление запоминает не только запрос, но и сортировку с областью поиска.

## Редактирование

Двойной клик по карточке, кнопка **«✎ Редактировать»** в просмотре, контекстное меню или `Ctrl/Cmd+N` открывают редактор в правой части экрана. Дерево и список остаются видимыми — можно переключаться между заметками, не закрывая окно.

- В шапке редактора появляется **«● не сохранено»**, если заголовок, текст, рейтинг или тэги отличаются от сохранённой версии.
- **Новая заметка создаётся без тэгов**, даже если открыта из папки: тэги добавляются вручную (или перетаскиванием заметки в ветку).
- **Рейтинг** ставится кликом по звезде в редакторе; он сохраняется вместе с заметкой и виден на карточке и в просмотре. Оценка не меняет дату обновления заметки.
- **Задачи** в Markdown (`- [ ]` / `- [x]`) можно отмечать прямо в просмотре — кликом или клавишами `Enter`/`Space`. Каждое изменение попадает в историю версий заметки.
- **Сохранить** сразу обновляет список и показывает заметку в режиме чтения.
- **Отмена**, `Esc` и **✕** закрывают редактор; при несохранённых правках приложение спросит подтверждение — несохранённые изменения будут потеряны.
- Переход в другую папку, заметку, тэг или поиск с несохранёнными правками тоже требует подтверждения — данные не теряются молча.
- На узких экранах (≤900px) редактор занимает весь контент, как и просмотр заметки.

## Внутренние ссылки

Ссылка `[[Заголовок другой заметки]]` в тексте открывает эту заметку (совпадение по заголовку без учёта регистра). Внизу просмотра появляется блок **«🔗 Обратные ссылки»** — заметки, которые ссылаются на текущую. Переход по ссылке очищает поиск, открывает папку целевой заметки и показывает её в правой панели.

## Быстрый переход (Ctrl+K)

Один список для всего: команды, папки/тэги, заметки и сохранённые фильтры. Нечёткий поиск понимает сокращения (`рбт` → `работа`). Префиксы сужают выдачу: `>` — только команды, `#` — только тэги, `@` — только заметки. `↑/↓` — выбор, `Enter` — переход, `Esc` — закрыть. `Ctrl+P` работает как алиас.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl/Cmd + N` | новая заметка |
| `Ctrl/Cmd + K` | быстрый переход (палитра) |
| `Ctrl/Cmd + P` | быстрый переход (алиас) |
| `/` | фокус в поиск |
| `Ctrl/Cmd + H` | поиск/замена в редакторе |
| `Ctrl/Cmd + Z` | отменить последнее опасное действие (до 20 шагов) |
| `Ctrl/Cmd + Shift + Z`, `Ctrl/Cmd + Y` | повторить отменённое действие |
| `Esc` | закрыть модальное окно, редактор или просмотр; очистить поиск |
| `↑ / ↓ / Enter / → / ←` | навигация по дереву, карточкам и палитре |
| `1–5` / `0` | поставить / сбросить оценку карточки в фокусе |

## Ограничения

- В дереве участвуют только первые 5 тэгов заметки (перестановки растут как `k!`).
- Большие списки рисуются порциями по 200 карточек с кнопкой «Показать ещё»; это не полноценная виртуализация — при прокрутке карточки остаются в DOM.
- Привязка локального файла после перезагрузки зависит от разрешений браузера.
- История заметки — 20 версий, корзина — 20, версионные снимки — 5, отмена — до 20 действий.
